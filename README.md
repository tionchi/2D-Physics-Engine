# 2D Physics Engine

## Overview
This project is a simple 2D physics engine built to explore the fundamentals of motion, forces, and collision handling.

The goal was to understand how basic physical systems can be simulated programmatically using vectors and kinematic equations.

## Features
- Vector-based motion
- Gravity simulation
- Basic collision detection and response
- Time-step based updates

## Concepts Explored
- SUVAT equations for motion
- Vector mathematics (position, velocity, acceleration)
- Discrete time simulation
- Basic collision handling

## Limitations
- Naive collision detection (O(n²))
- No spatial partitioning or optimisation
- Limited numerical stability handling
- No rotational dynamics

## Tech Stack
- Python
- Matplotlib / Pygame (for visualisation)

## What I Learned
- How to model physical systems using code
- The challenges of discrete simulation
- Limitations of naive approaches in scaling systems

## Future Improvements
- Implement spatial partitioning (e.g. grids or quadtrees)
- Improve collision resolution
- Add constraints (springs, joints)
- Explore performance optimisations

## Motivation
This project was built as a learning exercise to better understand the fundamentals of physics simulation and vector-based modelling.
